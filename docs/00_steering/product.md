# プロダクト概要（product.md）

> 全工程に共通する前提。AI はすべての作業でこの内容を前提にする。
> タスク管理拡張機能の要件定義の前提。

## 目的

- Web ページに関連するタスクを記録し、同じサイトに再訪した際に未完了のタスクを思い出せるようにする。

## 利用者

| 利用者 | 説明 | 主な利用場面 |
|---|---|---|
| 本人 | 自分の端末で拡張機能を利用する人 | Web ページに関連するタスクの登録、管理、確認 |

## スコープ

### 対象とする

- 通常の HTTP・HTTPS ページでのキーの組み合わせによるタスク登録画面の表示
- ページのドメイン、URL、タスク名、期限、詳細、スクリーンショットの登録
- タスクの一覧表示、編集、完了、削除、期限超過の表示
- 同じドメインへの再訪時の未完了タスクのリマインドと、タスク単位・ドメイン単位の期間指定による表示停止
- タスクと画像の端末内保存

### 対象としない

- ネットワーク経由のタスクや画像の同期
- 他の利用者とのタスク共有

## 成功の基準

- 対象ドメインのページを開いたとき、再読み込みしたとき、またはページ内遷移したとき、表示停止期間中でない対象の未完了タスクを 100% リマインド画面に表示する。

## 制約

- 配布: 本人のみが利用する。配布方法は未定。
- 対応ブラウザ: Google Chrome 最新版
- 予算・期間・その他の制約: 未定
