# FR-001 （サンプル）クリック回数のカウント

> 構成の動作確認用サンプルです。実際の要件定義を始めたら削除してください（BD-001 / DD-counter-001 / TS-001 と `src/`・`tests/` のサンプルも同様）。

## 1. 概要

利用者がポップアップのボタンを押した回数を数え、表示できるようにする。

## 2. 利用者と利用場面

拡張機能の利用者。ツールバーのアイコンからポップアップを開いたとき。

## 3. 前提条件

なし

## 4. 機能内容

| No | 内容 |
|---|---|
| 1 | ポップアップに現在のカウントを表示する |
| 2 | 「+1」ボタンでカウントを 1 増やす。上限は 999 |
| 3 | ブラウザを再起動してもカウントを保持する |

## 5. 受け入れ基準

- Given: カウントが 0
- When: 「+1」を押す
- Then: 表示が 1 になる

## 6. 対象外

カウントのリセット

なし
