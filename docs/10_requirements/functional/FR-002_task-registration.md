# FR-002 ページに関連するタスクの登録

## 1. 概要

利用者は、閲覧中の Web ページからタスクを登録し、後で対応できるようにする。

## 2. 利用者と利用場面

本人が Web ページを閲覧していて、後で行う作業を記録したいとき。

## 3. 前提条件

拡張機能が有効で、利用者が通常の HTTP・HTTPS ページを表示している。

## 4. 機能内容

| No  | 内容                                                                                                                                                                                                                                                     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 利用者が Ctrl+Shift+Y を押すと、登録・編集の操作がない場合はタスク登録画面を表示する。既に登録・編集が進行中の場合は新しい登録を開始せず、その旨と進行中の操作を完了または破棄する必要があることを表示する。                                             |
| 2   | 閲覧中のページのドメインと URL をタスクに関連付ける。                                                                                                                                                                                                    |
| 3   | タスク名を必須とし、期限とタスク詳細を任意で登録できる。                                                                                                                                                                                                 |
| 4   | 表示中の範囲または撮影開始時点で読み込み済みのページ範囲を選んでスクリーンショットを取得し、任意で登録できる。撮影のためのスクロールにより新たに読み込まれる内容は対象外とする。画像は1タスクにつき10枚まで、1枚につき5MB（5,000,000バイト）までとする。 |
| 5   | 登録したタスクと画像を端末内に保存する。                                                                                                                                                                                                                 |
| 6   | 登録・保存に失敗した場合、理由を表示し、入力内容を保持する。                                                                                                                                                                                             |
| 7   | 登録・編集は拡張機能全体で同時に1件とする。登録の保存成功または取消後に次の登録・編集を開始できる。                                                                                                                                                      |
| 8   | 登録画面が閉じた場合や Chrome が停止した場合も、進行中の操作を自動的に破棄しない。利用者は保存済みの途中入力を再開するか、明示的に破棄できる。途中入力の保存に失敗した場合は理由を表示する。再開時に復元するのは保存の成功を確認できた入力までとする。   |

## 5. 受け入れ基準

- Given: 通常の HTTP・HTTPS ページを表示しており、登録・編集が進行中ではない。
- When: Ctrl+Shift+Y を押す。
- Then: タスク登録画面が表示される。

- Given: 登録または編集が進行中である。
- When: 別のページで Ctrl+Shift+Y を押す。
- Then: 新しい登録は開始されず、進行中であることと、完了または破棄が必要なことが表示される。

- Given: 登録の途中入力が保存されている。
- When: 登録画面が閉じる、または Chrome が停止した後、拡張機能を再び利用する。
- Then: 保存済みの途中入力を再開または明示的に破棄できる。破棄するまでは別の登録・編集を開始できない。

- Given: 登録画面でタスク名を入力し、期限、詳細、スクリーンショットを指定する。
- When: タスクを登録する。
- Then: 入力内容と閲覧中のページのドメイン・URL が端末内に保存される。

- Given: 登録画面を表示している。
- When: 表示中の範囲または撮影開始時点で読み込み済みのページ範囲を選んでスクリーンショットを取得し、複数枚登録する。
- Then: 選んだ範囲の画像がタスクとともに保存される。

- Given: 撮影開始時点で読み込み済みのページ範囲を選択した。
- When: その範囲を撮影できない。
- Then: 撮影の失敗理由を表示し、入力内容を保持する。

- Given: タスクに10枚の画像がある、または追加する画像が5MBを超えている。
- When: 画像を追加しようとする。
- Then: 上限を超える画像は登録されず、上限を超えていることが分かる。

- Given: 登録画面でタスク名を入力しない。
- When: タスクを登録しようとする。
- Then: 登録されず、必須項目が不足していることが分かる。

- Given: 登録画面に入力内容がある。
- When: 登録・保存に失敗する。
- Then: 失敗理由が表示され、入力内容が保持される。

## 6. 対象外

ネットワーク経由でのタスクや画像の同期。通常の HTTP・HTTPS ページ以外からの登録。

## 7. 関連する非機能要件の候補

端末内データの保存容量、プライバシー、対応ブラウザ。

## 8. 未決事項

なし
