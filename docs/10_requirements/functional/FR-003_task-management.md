# FR-003 登録済みタスクの管理

## 1. 概要

利用者は登録したタスクを確認し、作業の進行に合わせて管理できる。

## 2. 利用者と利用場面

本人が登録済みタスクを確認、変更、完了または削除したいとき。

## 3. 前提条件

端末内に FR-002 で登録したタスクが存在する。

## 4. 機能内容

| No  | 内容                                                                                                                                                                                                                                                   |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 拡張機能アイコンから登録済みタスクを期限が近い順に一覧表示する。期限が同じ場合は登録日時の古い順、期限がない場合は期限のあるタスクの後に登録日時の古い順で表示する。完了・未完了とドメインで絞り込める。                                               |
| 2   | タスク名、URL、期限、詳細、画像を編集できる。画像は追加・個別削除・差し替えができる。URL の変更時にはドメインを自動更新し、ドメイン単独の編集はしない。                                                                                                |
| 3   | タスクを完了にでき、完了済みタスクを未完了に戻せる。                                                                                                                                                                                                   |
| 4   | タスクの削除時に確認を表示し、確認後に削除できる。                                                                                                                                                                                                     |
| 5   | 期限は日付で指定し、利用端末の現地日付で期限の翌日から未完了タスクを期限超過として表示する。完了済みタスクは期限超過として表示しない。                                                                                                                 |
| 6   | 登録・編集は拡張機能全体で同時に1件とする。登録・編集が進行中の場合、別の登録・編集、完了・未完了の変更、削除は行わず、その旨と進行中の操作を完了または破棄する必要があることを表示する。タスク一覧の表示と絞り込みは引き続き行える。                  |
| 7   | 編集画面が閉じた場合や Chrome が停止した場合も、進行中の操作を自動的に破棄しない。利用者は保存済みの途中入力を再開するか、明示的に破棄できる。途中入力の保存に失敗した場合は理由を表示する。再開時に復元するのは保存の成功を確認できた入力までとする。 |

## 5. 受け入れ基準

- Given: 複数のタスクが登録されている。
- When: タスク一覧を表示する。
- Then: 登録済みタスクが表示され、現地日付で期限の翌日以降の未完了タスクは期限超過と分かる。完了済みタスクは期限超過として表示されない。

- Given: 期限の異なるタスク、同じ期限のタスク、期限のないタスクが登録されている。
- When: タスク一覧を表示する。
- Then: 期限が近い順、同じ期限では登録日時の古い順、期限なしは最後に登録日時の古い順に表示される。

- Given: 完了・未完了のタスクと複数のドメインのタスクが登録されている。
- When: 完了状態またはドメインで一覧を絞り込む。
- Then: 指定条件に合うタスクのみ表示される。

- Given: 登録済みタスクがある。
- When: タスクを編集して保存する。
- Then: 変更した内容を再表示できる。

- Given: 登録または編集が進行中である。
- When: 別の画面から編集、完了・未完了の変更、または削除を行おうとする。
- Then: 変更は実行されず、進行中であることと、完了または破棄が必要なことが表示される。タスク一覧の表示と絞り込みはできる。

- Given: 編集の途中入力が保存されている。
- When: 編集画面が閉じる、または Chrome が停止した後、拡張機能を再び利用する。
- Then: 保存済みの途中入力を再開または明示的に破棄できる。破棄するまでは別の登録・編集を開始できない。

- Given: 画像付きの登録済みタスクがある。
- When: 画像を追加、個別削除または差し替えて保存する。
- Then: 変更後の画像を再表示できる。

- Given: 登録済みタスクがある。
- When: URL を変更して保存する。
- Then: 新しい URL に対応するドメインが保存される。

- Given: 未完了タスクがある。
- When: タスクを完了にする。
- Then: 完了状態が保存される。

- Given: 完了済みタスクがある。
- When: タスクを未完了に戻す。
- Then: 未完了状態が保存される。

- Given: 登録済みタスクがある。
- When: タスクを削除する。
- Then: 確認が表示され、削除を確認するとタスクは一覧に表示されない。

## 6. 対象外

他の利用者とのタスク共有。

## 7. 関連する非機能要件の候補

端末内データの保存容量、プライバシー。

## 8. 未決事項

- 画像の追加・差し替え・削除の操作方法、削除時の確認画面の詳細。
