# FR-004 対象ドメインでのタスクリマインド

## 1. 概要

利用者が対象ドメインのページを再訪した際に未完了タスクを確認し、作業を思い出せるようにする。

## 2. 利用者と利用場面

本人がタスク登録後、同じ対象ドメインの Web ページを開いたとき。

## 3. 前提条件

端末内に FR-002 で登録したタスクが存在する。

## 4. 機能内容

| No  | 内容                                                                                                                                                                                                                                                                                                       |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Chrome が拡張機能の動作を許可し、リマインド画面を表示できる対象ドメインの通常の HTTP・HTTPS ページを開く、再読み込みする、または URL が変わるページ内遷移をするたび、対象の未完了タスクをリマインド画面に表示する。画面表示中に URL が変わるページ内遷移をした場合は画面を重複させず、表示内容を更新する。 |
| 2   | 対象ドメインにはサブドメインを含める。例えば `www.example.com` のタスクは `shop.example.com` でも対象とする。`example.co.jp` のようなドメインも別サイトと混同しない。                                                                                                                                      |
| 3   | 完了済みタスクはリマインドしない。                                                                                                                                                                                                                                                                         |
| 4   | 利用者はタスク単位または対象ドメイン単位で、利用端末の現地日時による停止終了の日付と時刻を入力できる。停止は設定時に開始し、タスク一覧とリマインド画面から停止期間を変更・解除できる。                                                                                                                     |
| 5   | 停止期間中のタスク、または停止期間中の対象ドメインに属するタスクは表示しない。                                                                                                                                                                                                                             |
| 6   | 表示対象のタスクがない場合はリマインド画面を表示しない。                                                                                                                                                                                                                                                   |
| 7   | 対象タスクを一覧表示し、閉じるボタンでリマインド画面を閉じられる。                                                                                                                                                                                                                                         |
| 8   | `localhost` と IP アドレスは、ホストが完全一致した場合のみ同じ対象とする。                                                                                                                                                                                                                                 |
| 9   | 共有サービスの異なる利用者のサイトは別の対象ドメインとする。例えば `user-a.github.io` と `user-b.github.io` を区別する。                                                                                                                                                                                   |
| 10  | リマインドは独立した拡張機能画面に表示し、閲覧ページ上にはタスク内容や画像を表示しない。ページとコンテンツスクリプトは DOM を共有するため、表示方式の検討には REF-009 と REF-010 を参照する。                                                                                                              |
| 11  | 登録・編集が進行中の場合、停止期間の設定・変更・解除は行わず、その旨と進行中の操作を完了または破棄する必要があることを表示する。リマインド画面の表示・更新・閉じる操作は引き続き行える。                                                                                                                   |

## 5. 受け入れ基準

- Given: `www.example.com` に未完了タスクがあり、タスク・対象ドメインともに停止期間中ではない。
- When: `shop.example.com` のページを開く。
- Then: 対象の未完了タスクがリマインド画面に表示される。

- Given: 完了済みタスクがある。
- When: その対象ドメインのページを開く。
- Then: 完了済みタスクはリマインド画面に表示されない。

- Given: タスク単位または対象ドメイン単位の停止期間中である。
- When: 対象ドメインのページを開く。
- Then: 停止対象のタスクはリマインド画面に表示されない。

- Given: 登録または編集が進行中である。
- When: 一覧画面またはリマインド画面で停止期間の設定・変更・解除を行おうとする。
- Then: 停止設定は変更されず、進行中であることと、完了または破棄が必要なことが表示される。リマインドの表示・更新・閉じる操作はできる。

- Given: 停止期間が終了または解除され、ほかの停止期間の対象ではない未完了タスクがある。
- When: 対象ドメインのページを開く。
- Then: 対象タスクがリマインド画面に表示される。

- Given: リマインド画面が表示されている。
- When: 対象ドメインのページを再読み込みする、またはページ内遷移する。
- Then: 対象タスクが表示される。ページ内遷移時は画面が重複しない。

- Given: 対象ドメインのページが表示されている。
- When: ページの再読み込みを伴わず、URL が変わらない画面切り替えが起きる。
- Then: その画面切り替えを理由にリマインドを表示・更新しない。

- Given: 対象の未完了タスクがあり、停止期間中ではない。
- When: 対象ドメインのページを開く。
- Then: 独立した拡張機能画面に対象タスクが表示され、閲覧ページ上にはタスク内容や画像が表示されない。

- Given: 対象ドメインに表示対象のタスクがない。
- When: 対象ドメインのページを開く。
- Then: リマインド画面は表示されない。

- Given: `example.co.jp` に未完了タスクがある。
- When: 別サイト `other.co.jp` のページを開く。
- Then: `example.co.jp` のタスクは表示されない。

- Given: `localhost` または IP アドレスのページに未完了タスクがある。
- When: 別のホストのページを開く。
- Then: そのタスクは表示されない。

- Given: `user-a.github.io` に未完了タスクがある。
- When: `user-b.github.io` のページを開く。
- Then: `user-a.github.io` のタスクは表示されない。

## 6. 対象外

完了済みタスクのリマインド。通常の HTTP・HTTPS ページ以外、および Chrome が拡張機能の動作を許可しない、またはリマインド画面を表示できないページでのリマインド。ページの再読み込みを伴わない、URL が変わらない画面切り替えによるリマインド。

## 7. 関連する非機能要件の候補

ドメイン判定の正確性、プライバシー、対応ブラウザ。

## 8. 未決事項

- 対象ドメインの判定に使用する共有サービスの範囲と更新方法。
- 独立した拡張機能画面の表示方法と、複数タブからリマインドが発生した場合の扱い。
