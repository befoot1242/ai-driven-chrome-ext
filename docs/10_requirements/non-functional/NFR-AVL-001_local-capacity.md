# NFR-AVL-001 端末内の保存容量

分類: AVL

## 1. 要件

FR-002 と FR-003 のタスクデータと画像を、合計100MBまで端末内に保存できるようにする。

## 2. 目標値

| 指標                         | 目標値                                 | 測定条件                                                        |
| ---------------------------- | -------------------------------------- | --------------------------------------------------------------- |
| タスクデータと画像の合計容量 | 100MB（100,000,000バイト）まで保存可能 | 端末に必要な空き容量があり、FR-002 の画像ごとの上限を満たす場合 |

## 3. 測定・確認方法

合計100,000,000バイトのタスクデータと画像を保存し、再表示できることを確認する。確認用データの内容と容量の計算方法を記録する。

## 4. 根拠

FR-002、FR-003 と、利用者が指定した保存容量。

## 5. 未決事項

- 合計容量に含めるデータの範囲と容量の計算方法。
- 上限到達時の表示と、上限を超えるデータの扱い。
