# NFR-PERF-001 リマインドの表示時間

分類: PERF

## 1. 要件

FR-004 の表示対象となるタスクがある場合、リマインド画面を3秒以内に表示する。

## 2. 目標値

| 指標 | 目標値 | 測定条件 |
|---|---|---|
| 表示時間 | 測定したすべての操作で3秒以内 | ページ読み込み完了時またはページ内遷移時から、対象タスクがリマインド画面に表示されるまで |

## 3. 測定・確認方法

対象タスクを登録した HTTP・HTTPS ページの読み込み、再読み込み、ページ内遷移について、それぞれ表示時間を測定する。各測定で3秒以内であることを確認し、使用した端末・Chrome のバージョン・対象タスク数・試行回数を記録する。

## 4. 根拠

FR-004 と、利用者が指定した表示時間の目標。

## 5. 未決事項

- 測定する端末の性能、対象タスク数、各操作の試行回数。
- ページ内遷移の計測開始点を特定する具体的な方法。
