# NFR-SEC-001 タスクデータの外部送信禁止

分類: SEC

## 1. 要件

拡張機能は、タスクデータと画像を端末外へ送信しない。閲覧中の Web サイトへの送信も対象とする。

## 2. 目標値

| 指標 | 目標値 | 測定条件 |
|---|---|---|
| タスクデータ・画像の外部送信 | 0件 | タスクの登録、一覧表示、編集、完了、削除、リマインドの操作時 |

## 3. 測定・確認方法

テスト用データを使って各操作を実行し、拡張機能からのネットワーク通信と、閲覧ページに送信するデータを確認する。タスクデータと画像が送信されないことを確認する。

## 4. 根拠

FR-002、FR-003、FR-004 と、利用者が指定した端末内利用の方針。

## 5. 未決事項

- 検証対象とする通信・ページとのデータ受け渡しの具体的な観測方法。
