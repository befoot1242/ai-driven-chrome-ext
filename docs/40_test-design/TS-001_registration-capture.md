# TS-001 タスク登録と撮影

## 1. テスト対象と範囲

FR-002 の登録、表示範囲・読み込み済みページ範囲の撮影と、FR-003 の編集途中の撮影・再開を対象とする。画面・保存・通信を含む。対象外のページや撮影不能な場合は失敗として扱う。検証の結果が不明な場合は合格にせず、原因を記録する。

本書はテスト設計案であり、実装やテストの実行結果ではない。上流設計の撮影対象の識別、タブ切替との競合、所有者確認と復元通知は未確定である。

## 3. 手動テストとする理由

No.17 は、動的ページの開始時の内容、固定要素の重複、別オリジン iframe と復元状態の照合方法が未確定のため手動とする。自動化できる観測方法を確認した後に見直す。各 E2E の異常注入は実装・テスト方式が決まるまで具体的な注入方法を確定しない。

## 4. テストデータ

- 実データを使用しない HTTP・HTTPS ページと、識別用の文字・色・位置を持つ画像を用意する。
- 5,000,000 / 5,000,001 バイトの Blob は保存処理の境界試験に用いる。画像表示・撮影の試験には別途、実際に表示できる画像を用いる。
- 各テストは独立した拡張機能のテスト用プロファイルと保存領域で行い、実利用データを使わない。

## 5. カバーできていない要件

- あらゆるページの読み込み済み範囲の完全な識別、タブ切替と撮影のすべての競合、Worker 停止後の復元を、本書の有限のケースだけでは証明できない。
- 撮影結果の所有者認証・中断後の具体的な通知と整理方法は未決（DD-capture-001、DD-communication-001）。実施不能または観測不能の場合は未検証として設計に差し戻す。
