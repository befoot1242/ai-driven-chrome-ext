# ADR-0002 UI に Vue 3 を採用する案

## 状況

タスクの登録、一覧、編集、リマインドに複数の画面と状態管理が必要となる。利用者は Vue 3 を希望している。

## 決定

Vue 3 を UI 技術として提案する。Vue はコンポーネントと状態に基づく画面構築を提供する（REF-017）。拡張機能のコードはビルド時に同梱し、実行時にリモートコードを読み込まない。素の DOM と TypeScript のみで構築する方法も比較対象とした。

確認時点の候補は Vue 3.5.46 とする。パッケージのライセンス表記は MIT である（REF-027）。依存関係を含む実際の同梱物と配布条件の確認、および保守状況の確認は未了。

## 結果

- 画面をコンポーネントとして整理できる一方、依存関係とビルド設定が増える。
- 依存ライブラリのライセンス・保守状況、独立画面の表示・操作方法は未決。
- 承認後に技術スタックへの反映を行う。それまでは採用済みとしない。
