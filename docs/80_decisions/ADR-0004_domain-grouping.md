# ADR-0004 対象ドメイン判定に PSL を使用する案

## 状況

サブドメインをまとめつつ、`example.co.jp` と `other.co.jp`、共有サービス上の異なる利用者のサイトを区別する必要がある。

## 決定

共有サービスを含む Public Suffix List（PSL）を同梱し、対象ドメイン判定に使用する案とする。PSL はサイトのグループ化に利用できるが、ルールにはワイルドカードや例外がある（REF-015、REF-016）。単純に末尾2ラベルを比較する方式では要件を満たせない。

判定情報は拡張機能の更新時に更新し、実行時にタスクデータ・画像を外部送信しない。`localhost` と IP アドレスはホスト完全一致とする。

## 結果

- PSL の更新が拡張機能の更新まで反映されないため、判定情報が古くなる可能性がある。
- 判定ライブラリ・ライセンス、未知のドメインの扱い、PSL 更新に伴う既存データの再判定は未決。
